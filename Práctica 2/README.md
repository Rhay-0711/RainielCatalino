# Calculadora Matematica

Programa de consola en Java que suma, resta, multiplica y divide dos numeros usando un menu.

## Como se usa

Al ejecutarlo sale este menu:

```
1. Ingresar numero
2. Sumar
3. Restar
4. Multiplicar
5. Dividir
0. Salir
```

Primero elige la opcion 1 para ingresar los dos numeros. Despues puedes elegir cualquier operacion, y los numeros se quedan guardados hasta que ingreses otros.

## Ejemplo

```
Seleccione una opcion: 1
Ingrese el primer numero:
2
Ingrese el segundo numero:
2

Seleccione una opcion: 2
Resultado de la suma: 4

Seleccione una opcion: 5
Resultado division: 1
```

Si intentas dividir entre 0, el programa avisa y devuelve 0 en vez de fallar.
