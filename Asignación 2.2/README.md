# Asignación 2.2 - Clase Calculadora

En esta asignación se creó una clase `Calculadora` en Java con los métodos `sumar`, `restar`, `multiplicar` y `dividir`.

Se utilizaron métodos con 2 parámetros y se aplicó la sobrecarga de métodos para `sumar`, `restar` y `multiplicar` con 3 y 4 parámetros, utilizando `return` para devolver los resultados.
